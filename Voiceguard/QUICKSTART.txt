═══════════════════════════════════════════════════════════════
STEP 1: EXTRACT PROJECT
═══════════════════════════════════════════════════════════════

tar -xzf voiceguard.tar.gz
cd voiceguard

═══════════════════════════════════════════════════════════════
STEP 2: START DATABASE (Terminal 1)
═══════════════════════════════════════════════════════════════

Docker must be installed first.

docker run -d --name voiceguard-db \
  -e POSTGRES_USER=voiceguard \
  -e POSTGRES_PASSWORD=voiceguard \
  -e POSTGRES_DB=voiceguard \
  -p 5432:5432 \
  postgres:16-alpine

Wait 5 seconds for database to start.

═══════════════════════════════════════════════════════════════
STEP 3: START BACKEND (Terminal 2)
═══════════════════════════════════════════════════════════════

cd voiceguard/backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Linux/Mac:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

You should see:
  Uvicorn running on http://0.0.0.0:8000

═══════════════════════════════════════════════════════════════
STEP 4: START FRONTEND (Terminal 3)
═══════════════════════════════════════════════════════════════

cd voiceguard/frontend

# Install dependencies
npm install

# Run development server
npm run dev

You should see:
  VITE v5.0.0 ready in XXX ms
  Local: http://localhost:5173/

═══════════════════════════════════════════════════════════════
STEP 5: OPEN IN BROWSER
═══════════════════════════════════════════════════════════════

Go to: http://localhost:5173

You should see:
✅ VoiceGuard Dashboard
✅ Green connection indicator (top right)
✅ Stats cards
✅ Recent analyses
✅ Two buttons: Dashboard, Analyze Voice

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════
DOCKER COMPOSE ALTERNATIVE (Easier)
═══════════════════════════════════════════════════════════════

Instead of 3 terminals, use one command:

cd voiceguard
docker compose up --build

Then open: http://localhost:5173

To stop:
Press Ctrl+C
Or in another terminal:
docker compose down

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Can't access http://localhost:5173?
→ Check Terminal 3 is running npm dev
→ Check port 5173 is free

Can't access http://localhost:8000/api/health?
→ Check Terminal 2 is running uvicorn
→ Check port 8000 is free

Database connection error?
→ Check docker container is running: docker ps
→ Check credentials in .env match docker command

Virtual environment not activating?
→ Use: python -m pip install -r requirements.txt
→ Or: python -m venv venv (recreate it)
